Приложение представляет собой консольный чат. Приложение может быть запущено в режиме сервера или в режиме клиента (команды \server и \client соответственно). 
Пользоваться чатом могут только авторизованные пользователи. Для добавления новых пользователей необходимо на стороне сервера внести их логины и пароли (каждый пользователь на новой строке) в текстовый файл
(например Users.txt). При загрузке сервера необходимо указать путь к файлу с пользователями. Для сервера также необходимо указать открытый сетевой порт. Каждому клиенту необходимо указать ip-адрес и порт сервера, 
свой логин и пароль. После этого все авторизованные клиенты смогут обмениваться сообщениями. Чтобы отправить сообщение жирным шрифтом, необходимо в конце сообщения указать опцию \b, для отправки сообщения с красным цветом
опцию \r. Допустимо комбинировать опции: \rb. В настоящее время поддерживаются только TCP каналы для подключения. В приложение могут быть добавлены и другие каналы.
